## Purpose

Full-featured GitHub user search with profile pages, repos list, and follower stats.

## Use Cases

- Public REST API consumption
- Async state with Context API
- Dynamic routing with params

## Tech Stack

- React 16
- React Router v6
- Axios
- Create React App

## How to Run Locally

```bash
npm install && npm run dev
```

> On Node 17+, if build fails: `export NODE_OPTIONS=--openssl-legacy-provider`
